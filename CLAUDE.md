# CLAUDE.md

## Project notes

- dbt project over CVM open data (funds + FIDC). dbt project name: `cvm_funds_fidc_analytics`.
- Default target is **DuckDB** (`data/duckdb/cvm_dev.duckdb`); Snowflake is optional and reads all credentials from env vars.
- dbt lives in `dbt/`; it is both the project dir and the profiles dir (`dbt/profiles.yml`, copied from `dbt/profiles.yml.example`, gitignored).
- Use `make build` / `make parse` / `make docs`; Python deps are managed with `uv` (`pyproject.toml`, `uv.lock`). Regenerate `requirements.txt` with `make requirements` after changing deps.
- Layers: staging (views) → intermediate (views) → marts (tables). Cross-adapter SQL goes through `adapter.dispatch` macros in `dbt/macros/`.
- Raw CVM data is never committed. Only the small ODbL sample in `data/sample/` (phase 1) is versioned, attributed to CVM.
- English for code, comments, model names, docs and workflow names.

## Git conventions

Follow the `github-conventions` skill before any commit, branch, worktree, push, PR or merge. Summary:

- **Identity:** commit as Bruno Conejeros <brconejeros@gmail.com> using per-command config only:
  `git -c user.name="Bruno Conejeros" -c user.email="brconejeros@gmail.com" commit ...`
  Never change global/local git config; never use an AI identity.
- **No AI attribution:** no `Co-authored-by` trailers, no "generated by" notes, anywhere.
- **Messages:** Conventional Commits, in English, imperative mood, subject ≤72 chars (e.g. `feat(dbt): add stg_cvm__fidc_monthly`).
- **Never commit** secrets, `.env`, `dbt/profiles.yml`, generated files (`dbt/target/`, `dbt/dbt_packages/`, logs) or local data (`*.duckdb`, raw downloads).
- **Branches:** long-lived `main` (production) and `develop` (default/integration).
  - Always branch from `origin/develop`; `hotfix/*` branches from `origin/main`.
  - Never commit directly to `develop` or `main`.
  - Only `develop` or `hotfix/*` may open PRs into `main` (enforced by `.github/workflows/enforce-branch-flow.yml`).
- **Worktrees:** create under `.claude/worktrees/` (gitignored).
- **PRs required** for every change. Never merge without Bruno's explicit OK.
- **After merge:** remove the worktree first, then delete the branch (local and remote).
