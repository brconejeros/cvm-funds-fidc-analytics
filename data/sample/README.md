# data/sample/

Placeholder. In phase 1 this folder will hold a small versioned sample of CVM
open data so the project can be built and tested without downloading the full
datasets.

## Planned sample

- **Scope:** a deterministic subset of fund CNPJs (fixed, documented selection
  rule — e.g. a stable hash of the CNPJ — so the sample is reproducible).
- **Period:** 2021–2026, covering the transition to CVM Resolution 175.
- **Size:** roughly 10–20 MB in total.
- **Datasets:** fund registry, daily reports and FIDC monthly reports for the
  selected CNPJs.
